# 이클립스 필드보스 타이머 Web

Windows용 EclipseBossTimer의 보스 목록과 시간 계산을 옮긴 반응형 웹 앱입니다. HTML, CSS, JavaScript로 구성되어 패키지 설치나 빌드 없이 실행할 수 있습니다.

## 실행

상위 폴더의 **start-web.cmd**를 더블클릭합니다. Node.js가 필요하며 현재 PC에는 설치되어 있습니다. 서버가 백그라운드에서 시작되고 기본 브라우저로 http://127.0.0.1:4173 을 엽니다.

개발 중 터미널에서 실행하려면 이 폴더에서:

~~~sh
npm start
~~~

이 방식은 Ctrl+C로 서버를 종료할 수 있습니다. 이미 실행 중이면 주소로 바로 접속합니다. 다른 포트는 PORT 환경 변수로 지정합니다. 서버는 이 PC의 루프백 주소에만 바인딩합니다.

## 옮긴 기능

- Lv.40 / 50 / 60 / 70 / 75 / 80, 각각 8 / 8 / 10 / 12 / 12 / 15시간 주기
- 한국시간(UTC+9) 기준 반복 계산, 현재 시각보다 엄격하게 다음인 회차 표시
- 보스별 또는 전체 기준 날짜·시각과 리젠 간격 수정
- 개별·전체 초기화 및 마지막 초기화/설정 불러오기 되돌리기
- 5분 이내 리젠 강조, 레벨순/임박순 정렬
- 리젠 알림음과 소리 테스트
- 브라우저 저장, 같은 브라우저의 탭 사이 설정 반영
- Windows와 호환되는 JSON 설정 내보내기/불러오기

초기 기준은 2026-10-22이며, 이 PC에서 확인한 저장 설정을 반영했습니다.

| 레벨 | 기준 시각 (KST) | 반복 주기 |
| --- | --- | --- |
| 40 | 18:02:00 | 8시간 |
| 50 | 18:04:00 | 8시간 |
| 60 | 14:03:00 | 10시간 |

원본 EXE의 기본 Lv.75 시각은 18:08이지만, 사용자가 저장한 설정은 18:15이므로 저장된 값을 사용했습니다. 참고용 원본 소스는 상위 reference/boss_timer.py에 보존했습니다.

## 저장과 알림

설정은 현재 브라우저와 주소의 localStorage에 저장됩니다. 서버에 설정을 전송하지 않습니다. 다른 PC/브라우저/접속 주소 사이에는 자동으로 동기화되지 않으므로 JSON 파일을 내보내고 불러옵니다. Windows 설정 파일은 %LOCALAPPDATA%\EclipseBossTimer\settings.json 입니다.

알림음은 사용자의 클릭으로 오디오를 활성화한 열린 탭에서 작동합니다. 다시 열었을 때 알림음이 켜져 있으면 소리 테스트를 눌러 활성화합니다. 절전이나 백그라운드 탭 제한으로 알림이 늦거나 생략될 수 있습니다. 2분 넘게 중단된 뒤에는 지난 알림을 몰아서 재생하지 않습니다. 카운트다운은 복귀 시 기준 시각에서 다시 계산합니다. 웹에서는 데스크톱의 '항상 위에' 창 고정을 제공하지 않습니다.

## 검증

~~~sh
npm test
node tests/browser.mjs
~~~

브라우저 검증은 로컬 서버 실행 후 설치된 Chrome의 독립된 임시 프로필을 사용합니다. CHROME_PATH 환경 변수로 다른 Chromium 브라우저를 지정할 수 있습니다. 결과와 화면 캡처는 .local/에 저장됩니다.

## 파일

- dist/index.html, style.css: 반응형 화면
- dist/core.js: 시간대, 반복 계산, 설정 검증
- dist/app.js: 사용자 조작, 저장, 알림
- server.mjs: 정적 파일만 제공하는 로컬 서버
- start.mjs: Windows 간편 실행
- tests/: 계산 및 브라우저 검증
- .openai/hosting.json: 비공개 Sites 식별자와 정적 배포 설정

dist/를 정적 웹 호스팅에 올릴 수 있습니다. 호스팅 공개 상태는 실제 배포 결과를 확인해야 하며, 사이트 등록만으로 배포가 완료되는 것은 아닙니다.
